# SuperSoft — Software Company

Landing page corporativa de alto impacto para **SuperSoft — Software Company**, empresa especializada en desarrollo de páginas web comerciales, sistemas ERP y CRM a medida, y soluciones robustas en **Laravel 11 & React**.

---

## 🚀 Tecnologías & Arquitectura

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Frontend & UI:** [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones & Interactividad:** [Framer Motion](https://www.framer.com/motion/), [Lucide React](https://lucide.dev/)
- **Tipografía:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [Inter](https://fonts.google.com/specimen/Inter)
- **Despliegue:** Optimizado para [Vercel](https://vercel.com/)

---

## 🛠️ Instalación y Desarrollo Local

1. Clonar el repositorio:
```bash
git clone https://github.com/jabarmagdiel/supersoft.git
cd supersoft
```

2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

4. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

---

## ⚡ Despliegue en Vercel

Este proyecto está preconfigurado para un despliegue directo en Vercel con cero configuración:

1. Ingresa a [Vercel](https://vercel.com/) y haz clic en **Add New... > Project**.
2. Conecta tu cuenta de GitHub e importa el repositorio `jabarmagdiel/supersoft`.
3. Vercel detectará automáticamente:
   - **Framework Preset:** `Next.js`
   - **Build Command:** `npm run build`
   - **Output Directory:** `.next`
4. Haz clic en **Deploy**. ¡Listo en menos de 1 minuto!
